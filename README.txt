ECE 314 Circuit Studio Website Update
Revised September 28, 2026

INSTALL
1. Keep a backup of your current course website.
2. Extract this ZIP and merge its contents into the existing course-site root.
   Replace index.html and Circuit_Studio.html when prompted.
3. Keep the guides folder beside index.html. The two updated Word documents
   must retain the filenames supplied in this package.
4. Keep your existing module files, homework files, assets, and other guides,
   including guides/Student_Workspace_Quick_Guide.docx.
5. Open index.html and use the Circuit Studio section to launch the app and
   download the Student Study Guide and Student Manual.

WHAT CHANGED
- Simplified the homepage: eight compact module cards with key-topic labels,
  four Circuit Studio family cards with worked-example counts, and concise
  homework rows with problem and point totals.
- Full topics, simulation notes, and course information expand on demand.
  Search, filters, progress, light/dark themes, and guide downloads remain.
- Revised Circuit Studio homepage section, device-family descriptions,
  study workflow, simulation overview, and optional voice help.
- Fixed all four device-family links. Each opens the selected family's
  starting circuit and topic list even when another circuit was saved.
  The generic launch button still restores the last drawing. Undo can
  restore the previous sheet after opening a family link.
- Added direct downloads for both updated student documents.
- Added AC and transient exercises with verified RC results, bias
  investigations, probes and exports, and model limitations.
- Corrected output-resistance guidance: the teaching T models omit r_o;
  compare representations using matching assumptions.
- Updated screenshots and voice troubleshooting guidance.

This is an update package for your existing eight-module course website.
The module and homework files are not included. Circuit_Studio.html is the
current app with the matching device-link routing fix. Upload BOTH HTML
files together for the links to work. No API key is included. The core editor,
lessons, Tutor, and simulation do not require a Gemini API key.
