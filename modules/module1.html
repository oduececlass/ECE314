Mathematical roadmap

The same feedback framework connects every circuit in this module.

From device equation to closed-loop circuit

For the canonical voltage-feedback form, apply the source to the noninverting input and return \(v_-=βv_o\). This makes the loop-gain idea explicit; inverting topologies use the same feedback principle but their signal gain is most directly obtained from KCL.

Open-loop relation\(v_o=A_{OL}(s)(v_+-v_-)\). A very large \(A_{OL}\) makes the differential input extremely small during linear operation.
Feedback relationThe external resistor network returns a fraction or linear combination of the output to the inverting terminal.
Closed-loop resultThe desired gain is determined mainly by resistor ratios when the loop gain \(T=A_{OL}\beta\) is large.
\[ \boxed{ A_{CL}(s)=\frac{A_{OL}(s)}{1+A_{OL}(s)\beta(s)} } \qquad \boxed{ e(s)=v_+(s)-v_-(s)=\frac{v_s(s)}{1+T(s)} } \]

The quantity \(T(s)=A_{OL}(s)\beta(s)\) is the loop gain. Large loop gain reduces gain error, output resistance, nonlinear distortion, and sensitivity to internal op-amp parameters. It may also introduce stability concerns if phase shift approaches \(180^\circ\) before \(|T|<1\).

Recommended analysis sequence: identify feedback → verify linear operation → apply ideal rules → write KCL/KVL → solve symbolically → check rail, current, bandwidth, and tolerance constraints.

Topic 1.1

Ideal Op-Amp + Negative Feedback

Begin with the op-amp symbol and terminal notation, then study how negative feedback reduces input error and prevents immediate saturation.

Start here · Device symbol and notation

What is an operational amplifier?

An operational amplifier, or op-amp, is a high-gain differential voltage amplifier. It senses the difference between two input voltages and produces one output voltage. The triangular symbol represents the op-amp as a functional circuit block; the many transistors, current sources, and compensation elements inside the device are not shown.

Standard op-amp symbol

The \(+\) and \(−\) signs identify input polarity; they are not the power-supply terminals. The power rails \(+V_S\) and \(−V_S\) provide energy to the circuit.

Meaning of the symbols

\(v_+\)Voltage at the noninverting input.
\(v_-\)Voltage at the inverting input.
\(v_d=v_+-v_-\)Differential input voltage.
\(v_o\)Output voltage measured relative to the reference node.
\(i_+,\,i_-\)Currents entering the two input terminals.
\(i_o\)Current delivered or absorbed by the output terminal.
\(+V_S,\,-V_S\)Positive and negative power-supply rails.
\(A_{OL}\)Open-loop differential voltage gain.
\[ \boxed{ v_o=A_{OL}v_d=A_{OL}(v_+-v_-) } \]

The subscript OL means open loop: no external feedback path has yet been connected from the output to an input. This notation distinguishes \(A_{OL}\) from a closed-loop gain such as \(A_{CL}=v_o/v_s\) or \(A_v\).

Notation used throughout this module: the open-loop gain is written \(A_{OL}\), while \(A_{CL}\) or \(A_v\) denotes a closed-loop circuit gain. Keeping these symbols distinct prevents a common source of analysis errors.

Detailed theory: ideal model, loop gain, and finite-gain error

The virtual short is a consequence of negative feedback and large gain—not an independent physical law.

1. Differential-input model and ideal assumptions

The fundamental large-signal relation is

\[ v_o=A_{OL}(v_+-v_-)=A_{OL}v_d \]

A practical op-amp has large but finite open-loop gain \(A_{OL}\), very large input resistance, and nonzero output resistance. The ideal model takes the limiting values

\[ A_{OL}\rightarrow\infty,\qquad R_{in}\rightarrow\infty,\qquad R_o\rightarrow0,\qquad i_+=i_-=0. \]

When the output remains between its allowable rails and negative feedback is active, a finite output requires

\[ v_d=v_+-v_-=\frac{v_o}{A_{OL}}\longrightarrow0, \qquad\therefore\qquad v_+\approx v_-. \]
Important: \(v_+\approx v_-\) is valid only in the linear negative-feedback region. It does not apply during saturation, open-loop comparator operation, or positive feedback.
2. General negative-feedback derivation

For a source \(v_s\) applied to the noninverting input and a feedback fraction \(v_-=\beta v_o\),

Write the op-amp relation: \[ v_o=A_{OL}(v_s-\beta v_o). \]
Collect the output terms: \[ v_o(1+A_{OL}\beta)=A_{OL}v_s. \]
Solve for the closed-loop gain: \[ \boxed{\frac{v_o}{v_s}=\frac{A_{OL}}{1+A_{OL}\beta}}. \]

If \(A_{OL}\beta\gg1\), then

\[ \frac{v_o}{v_s}\approx\frac{1}{\beta}, \qquad \frac{v_s-\beta v_o}{v_s}=\frac{1}{1+A_{OL}\beta}. \]

Thus the fractional error is approximately \(1/T\), where \(T=A_{OL}\beta\).

3. Sensitivity, desensitivity, and feedback accuracy

The sensitivity of closed-loop gain to open-loop gain is

\[ S_{A_{OL}}^{A_{CL}} =\frac{\partial A_{CL}/A_{CL}}{\partial A_{OL}/A_{OL}} =\frac{1}{1+A_{OL}\beta} =\frac{1}{1+T}. \]

A 10% change in \(A_{OL}\) therefore produces only approximately \(10\%/(1+T)\) change in closed-loop gain. This is the mathematical origin of gain stability under negative feedback.

Input error\(v_d=v_o/A_{OL}\), small but generally not exactly zero.
Output resistance\(R_{o,CL}\approx R_o/(1+T)\) for voltage-series feedback.
LinearityInternal nonlinear error is reduced approximately by the desensitivity factor \(1+T\).
4. Frequency-domain model and stability

A common first-order open-loop approximation is

\[ A_{OL}(s)=\frac{A_0}{1+s/\omega_p}. \]

Substitution into the feedback equation gives

\[ A_{CL}(s) =\frac{A_0}{1+A_0\beta} \frac{1}{1+s/\left[\omega_p(1+A_0\beta)\right]}. \]

Negative feedback reduces low-frequency gain while increasing bandwidth by approximately the same factor. For a unity-gain-stable op-amp with gain-bandwidth product \(f_T\),

\[ f_{CL}\approx\frac{f_T}{\text{noise gain}}. \]

Stable operation requires adequate phase margin at the loop-gain crossover \(|T(j\omega_c)|=1\). The introductory simulation uses a static model and therefore does not display phase-margin effects.

5. Saturation and the linear-operating test

The algebraic closed-loop result must satisfy the output constraint

\[ V_{OL}\le v_o\le V_{OH}, \]

where \(V_{OH}\) and \(V_{OL}\) are the positive and negative output limits. If the required output violates this interval, the actual output clips and the virtual-short approximation no longer holds.

Simulation task: select negative feedback, increase \(A_{OL}\), and observe that \(v_+-v_-\) approaches zero. Then reduce the rails until the output saturates and watch the virtual-short condition fail.

Example 1.1-A

How narrow is the open-loop linear region?

open loopsaturation
Problem. An op-amp with \(A_{OL}=2\times10^{5}\) is used without feedback. Its output saturates at \(\pm12\,\text{V}\). The inputs are \(v_+=0.50\,\text{mV}\) and \(v_-=0.20\,\text{mV}\). Find the differential input that just saturates the output, the output the linear model predicts, and the actual output.
\(A_{OL}=2\times10^{5}\)\(V_{sat}=\pm12\,\text{V}\)\(v_+=0.50\,\text{mV}\)\(v_-=0.20\,\text{mV}\)
  1. Width of the linear windowWhat differential input \(|v_d|\) drives the output exactly to the rail?
    \[|v_d|_{sat}=\frac{V_{sat}}{A_{OL}}=\frac{12}{2\times10^{5}}=6.0\times10^{-5}\,\text{V}=60\,\mu\text{V}\]

    Any differential input larger than about \(60\,\mu\text{V}\) saturates the output.

  2. Applied differential inputCompute \(v_d=v_+-v_-\).
    \[v_d=0.50-0.20=0.30\,\text{mV}\]

    This is five times larger than the linear window found in step 1.

  3. Unclipped (linear-model) outputEvaluate \(A_{OL}v_d\) with no rail limit.
    \[A_{OL}v_d=(2\times10^{5})(0.30\times10^{-3}\,\text{V})=60\,\text{V}\]

    The linear model demands \(60\,\text{V}\) — physically impossible with \(\pm12\,\text{V}\) rails.

  4. Actual outputApply the rail limit.
    \[v_o=\operatorname{clip}(60\,\text{V},-12,+12)=+12\,\text{V}\]
  5. InterpretWhat does this say about using an op-amp open loop?

    Open loop, the op-amp behaves as a comparator: its output is \(+V_{sat}\) whenever \(v_+>v_-\) by more than a few tens of microvolts and \(-V_{sat}\) in the opposite case. Microvolt-level noise or offset is enough to flip it. Controlled linear amplification is only possible when negative feedback holds \(v_d\) inside that tiny window automatically.

Answer. \(|v_d|_{sat}=60\,\mu\text{V}\); the linear model predicts \(60\,\text{V}\); the actual output is \(+12\,\text{V}\) (saturated).
Example 1.1-B

Finite open-loop gain inside a feedback loop

negative feedbackloop gaindesensitivity
Problem. An op-amp with \(A_{OL}=10^{4}\) is placed in a non-inverting loop with feedback factor \(\beta=0.1\) and driven by \(v_s=0.5\,\text{V}\). Find the ideal gain, the loop gain, the actual gain, the output, and the residual differential input. Then find how much the closed-loop gain changes if \(A_{OL}\) drops by 50 % (to \(5\times10^{3}\)).
\(A_{OL}=10^{4}\)\(\beta=0.1\)\(v_s=0.5\,\text{V}\)
  1. Ideal gainWhat is the gain when \(A_{OL}\to\infty\)?
    \[A_{CL,ideal}=\frac{1}{\beta}=\frac{1}{0.1}=10\]
  2. Loop gainCompute \(T=A_{OL}\beta\).
    \[T=(10^{4})(0.1)=1000\]
  3. Actual closed-loop gainUse \(A_{CL}=A_{OL}/(1+T)\).
    \[A_{CL}=\frac{10^{4}}{1+1000}=9.9900\qquad\left(=10\cdot\frac{1000}{1001}\right)\]

    The gain falls short of the ideal value by about \(1/T=0.1\%\).

  4. Output voltageCompute \(v_o=A_{CL}v_s\).
    \[v_o=(9.9900)(0.5)=4.995\,\text{V}\]
  5. Residual differential inputHow far apart are \(v_+\) and \(v_-\)? Use \(v_d=v_o/A_{OL}\).
    \[v_d=\frac{4.995\,\text{V}}{10^{4}}=0.4995\,\text{mV}\]

    Check: \(v_-=\beta v_o=0.4995\,\text{V}\), so \(v_+-v_-=0.5-0.4995=0.5\,\text{mV}\). The inputs differ by half a millivolt while the signals are half a volt — this is the "virtual short".

  6. Sensitivity to \(A_{OL}\)Recompute \(A_{CL}\) with \(A_{OL}=5\times10^{3}\) and find the percentage change.
    \[A_{CL}'=\frac{5000}{1+500}=9.9800,\qquad \frac{A_{CL}'-A_{CL}}{A_{CL}}=\frac{9.9800-9.9900}{9.9900}\approx-0.0998\%\]

    A 50 % loss of open-loop gain moved the closed-loop gain by only 0.1 %. This is the desensitivity of negative feedback: errors inside the loop are divided by roughly \(1+T\).

Answer. Ideal gain 10; \(T=1000\); \(A_{CL}=9.990\); \(v_o=4.995\,\text{V}\); \(v_d\approx0.50\,\text{mV}\); halving \(A_{OL}\) changes \(A_{CL}\) by only \(-0.1\%\).

How the inverting amplifier is built from an op-amp

The inverting amplifier is formed by grounding the noninverting terminal, applying the source voltage \(v_i\) through an input resistor \(R_1\), and returning the output through a feedback resistor \(R_f\) to the same summing node. The op-amp still obeys the open-loop law \(v_o=A_{OL}(v_+-v_-)\), but negative feedback constrains the summing-node voltage and makes the overall gain depend mainly on the resistor ratio.

Inverting-amplifier topology

\(R_1=10~\text{k}\Omega\)
\(R_f=40~\text{k}\Omega\)

The node voltage \(v_n\) is the inverting-input or summing-node voltage. In ideal linear operation, negative feedback forces this node close to 0 V, creating a virtual ground.

Core mathematics of the inverting configuration

\(v_+=0\)The noninverting input is physically connected to ground.
\(v_-=v_n\)The inverting terminal is the summing node.
\(i_-=0\)The ideal op-amp input draws no current.
\(A_{OL}\)Open-loop gain of the underlying op-amp.
\[ \boxed{ v_o=A_{OL}(v_+-v_-)=A_{OL}(0-v_n)=-A_{OL}v_n } \]
\[ \boxed{ \frac{v_n-v_i}{R_1}+\frac{v_n-v_o}{R_f}=0 } \qquad \text{(KCL at the summing node)} \]
\[ \text{Ideal limit:}\quad v_n\approx 0 \quad\Longrightarrow\quad \boxed{ \frac{v_o}{v_i}=-\frac{R_f}{R_1} } \]
Exact finite-gain result using \(A_{OL}\)

Do not set \(v_n=0\) immediately. From the op-amp relation,

\[ v_n=-\frac{v_o}{A_{OL}}. \]

Substituting this into the KCL equation gives the exact closed-loop gain:

\[ \boxed{ \frac{v_o}{v_i} =-\frac{A_{OL}R_f} {A_{OL}R_1+R_1+R_f} } =-\frac{R_f/R_1} {1+\dfrac{1+R_f/R_1}{A_{OL}}}. \]

As \(A_{OL}\to\infty\), this expression approaches the ideal result \(-R_f/R_1\). This is why the inverting amplifier is analyzed by combining the op-amp law with KCL rather than memorizing the gain formula alone.

Detailed theory: summing-node KCL, finite gain, noise gain, and design limits

The signal gain is set by \(R_f/R_1\), while the feedback loop is governed by the larger noise gain \(1+R_f/R_1\).

1. Ideal closed-loop gain from KCL

With \(v_+=0\), negative feedback forces \(v_-\approx0\). Since the input current of the op-amp is zero, KCL at the summing node gives

\[ \frac{v_i-v_-}{R_1}+\frac{v_o-v_-}{R_f}=0. \]
Set \(v_-\approx0\): \[ \frac{v_i}{R_1}+\frac{v_o}{R_f}=0. \]
Solve: \[ \boxed{v_o=-\frac{R_f}{R_1}v_i}. \]

The negative sign represents a \(180^\circ\) phase reversal for a sinusoidal input. The source sees

\[ \boxed{R_{in}=R_1}. \]

The resistor current is

\[ i_1=\frac{v_i}{R_1} =-\frac{v_o}{R_f}=i_f, \]

which explains the current-steering interpretation of the circuit.

2. Exact gain with finite open-loop gain

Do not impose \(v_-=0\) exactly. Instead use

\[ v_o=A_{OL}(0-v_-)\quad\Rightarrow\quad v_-=-\frac{v_o}{A_{OL}}. \]

Substitute this expression into the node equation and solve:

\[ \boxed{ \frac{v_o}{v_i} =-\frac{A_{OL}R_f}{A_{OL}R_1+R_1+R_f} =-\frac{R_f/R_1}{1+\dfrac{1+R_f/R_1}{A_{OL}}} }. \]

For \(A_{OL}\gg1+R_f/R_1\), the ideal gain is recovered. The approximate relative gain error is

\[ \epsilon_G \approx-\frac{1+R_f/R_1}{A_{OL}}. \]
3. Signal gain, noise gain, and bandwidth

The inverting signal gain and noise gain are different:

QuantityExpressionMeaning
Signal gain\(\displaystyle A_v=-R_f/R_1\)Gain from the applied input source to the output.
Feedback factor\(\displaystyle \beta=R_1/(R_1+R_f)\)Fraction of output returned to the inverting node when the input source is set to zero.
Noise gain\(\displaystyle 1/\beta=1+R_f/R_1\)Gain experienced by input-referred op-amp voltage noise and offset.

For a single-pole unity-gain-stable op-amp,

\[ f_{-3\,\mathrm{dB}}\approx \frac{f_T}{1+R_f/R_1}. \]

Therefore, a signal gain magnitude of 10 has a noise gain of 11 and approximately \(f_T/11\) bandwidth.

4. Output clipping, resistor power, and current limits

For symmetrical rails \(\pm V_{sat}\), the largest unclipped input amplitude is approximately

\[ |v_{i,\max}|\approx \frac{V_{sat}}{|A_v|} =V_{sat}\frac{R_1}{R_f}. \]

Peak feedback current and resistor power are

\[ |i_{f,\mathrm{pk}}|=\frac{|v_{o,\mathrm{pk}}|}{R_f}, \qquad P_{R_f,\mathrm{rms}}=\frac{V_{o,\mathrm{rms}}^2}{R_f}. \]

The op-amp must supply both feedback-network current and load current:

\[ i_o=i_f+i_L. \]

Even when the voltage is inside the rails, excessive output current can produce current limiting and waveform distortion.

5. Extensions: weighted summing amplifier and transimpedance form

Multiple input resistors connected to the same virtual-ground node produce

\[ \boxed{ v_o=-R_f\left( \frac{v_1}{R_1}+ \frac{v_2}{R_2}+\cdots+ \frac{v_n}{R_n} \right)}. \]

If the input is a current source rather than a voltage through \(R_1\), the circuit becomes a transimpedance amplifier:

\[ \boxed{v_o=-i_{in}R_f}. \]
Simulation task: double \(R_f\) and verify that output amplitude doubles, bandwidth would decrease through the noise gain, and the maximum unclipped input amplitude is cut in half.

Start here · Noninverting amplifier overview

What is a noninverting op-amp?

In a noninverting amplifier, the input signal is applied to the noninverting \((+)\) terminal of the op-amp. A negative-feedback network connects the output back to the inverting \((-)\) terminal, so the output stays in phase with the input while the closed-loop gain is set by external resistors rather than by the very large open-loop gain \(A_{OL}\).

Noninverting topology

The signal enters the \(+\) input. The feedback divider returns a fraction of \(v_o\) to the \(−\) input, so the output remains in phase with \(v_i\).

Key ideas

\(v_+=v_i\)The source is applied directly to the noninverting input.
\(v_-\approx v_+\)Negative feedback drives the differential error toward zero.
In-phase outputThe output polarity matches the input polarity.
\(A_v=1+\dfrac{R_f}{R_1}\)The feedback divider sets the ideal gain.
\[ \boxed{ \frac{v_o}{v_i}=1+\frac{R_f}{R_1} } \qquad \text{and for a follower}\qquad \boxed{ \frac{v_o}{v_i}=1 } \]

The voltage follower or buffer is the special unity-gain case in which the output is fed directly back to the inverting terminal.

Why it is useful

The noninverting configuration provides high input impedance, because the source drives the op-amp input directly, and the op-amp input current is ideally zero. At the same time, negative feedback produces a low effective output impedance, making the circuit useful as both an amplifier and a buffer stage.

\[ v_o=A_{OL}(v_+-v_-),\qquad v_-\approx v_+=v_i \]

The vector topology below shows the general noninverting configuration; the voltage follower is the unity-gain special case obtained by feeding \(v_o\) directly to the inverting input.

Detailed theory: non-inverting gain derivation, voltage follower, and bandwidth

The general non-inverting configuration and its unity-gain follower share the same feedback principle. In both, the signal is applied to the noninverting terminal, so the output remains in phase with the input. The general configuration has gain \(1+R_f/R_1\), whereas the follower has unity gain.

1. Ideal gain from the feedback divider

No current enters the inverting terminal, so \(R_f\) and \(R_1\) form an unloaded divider:

\[ v_-=\beta v_o,\qquad \beta=\frac{R_1}{R_1+R_f}. \]

Negative feedback forces \(v_-=v_+=v_i\). Therefore,

\[ v_i=\frac{R_1}{R_1+R_f}v_o. \]
\[ \boxed{ \frac{v_o}{v_i} =\frac{R_1+R_f}{R_1} =1+\frac{R_f}{R_1}}. \]

The minimum ideal gain is 1 because \(R_f\ge0\). A gain smaller than 1 requires attenuation before the noninverting input or a different topology.

2. Finite open-loop gain and gain error

Using \(v_o=A_{OL}(v_i-\beta v_o)\),

\[ \boxed{ \frac{v_o}{v_i} =\frac{A_{OL}}{1+A_{OL}\beta} =\frac{1/\beta}{1+\dfrac{1}{A_{OL}\beta}} }. \]

Since \(1/\beta=1+R_f/R_1\),

\[ \frac{v_o}{v_i} = \frac{1+R_f/R_1} {1+\dfrac{1+R_f/R_1}{A_{OL}}}. \]

The approximate fractional gain error is

\[ \epsilon_G\approx-\frac{1+R_f/R_1}{A_{OL}}. \]

This is mathematically identical to the finite-gain correction associated with the inverting circuit’s noise gain.

3. Voltage follower as a limiting case

Directly connecting the output to the inverting input gives \(\beta=1\):

\[ A_{CL}=\frac{A_{OL}}{1+A_{OL}} \approx1-\frac{1}{A_{OL}}. \]

The follower does not increase voltage amplitude, but it transforms impedance. For voltage-series feedback, approximately

\[ R_{in,CL}\approx R_{in}(1+T), \qquad R_{o,CL}\approx\frac{R_o}{1+T}. \]

Thus a weak source can drive a heavier load without substantial source-voltage loss, provided the output current and swing remain within the op-amp limits.

4. Bandwidth, slew rate, and full-power bandwidth

For a single-pole op-amp, the noninverting noise gain equals the signal gain:

\[ \text{noise gain}=1+\frac{R_f}{R_1}, \qquad f_{-3\,\mathrm{dB}}\approx \frac{f_T}{1+R_f/R_1}. \]

Large-signal sine-wave performance may instead be limited by slew rate \(SR\). Since

\[ v_o(t)=V_p\sin(2\pi ft) \quad\Rightarrow\quad \max\left|\frac{dv_o}{dt}\right|=2\pi fV_p, \]

undistorted operation requires

\[ 2\pi fV_p\le SR, \qquad \boxed{f_{\mathrm{FPBW}}=\frac{SR}{2\pi V_p}}. \]

The present simulation models rail clipping but not slew-rate distortion.

5. Loading and output-range design checks

The ideal closed-loop output is

\[ v_o=\left(1+\frac{R_f}{R_1}\right)v_i. \]

For symmetrical output limit \(V_{sat}\),

\[ |v_{i,\max}| \approx\frac{V_{sat}} {1+R_f/R_1}. \]

The feedback-divider current is

\[ i_{div}=\frac{v_o}{R_f+R_1}. \]

A smaller divider resistance reduces bias-current-induced errors but increases output loading and power consumption. A larger divider resistance saves current but increases thermal-noise and bias-current sensitivity.

Topic 1.4

Difference Amplifier

Amplify \(v_2-v_1\), reject common-mode content, and see how resistor mismatch degrades rejection.

1Learn→ 2Explore→ 3Guided practice→ 4Check

Difference-amplifier topology

Use the four-resistor network to separate differential signal from common-mode signal.

Vector circuit
Differential actionWith matched ratios, \(v_o=(R_2/R_1)(V_2-V_1)\).
Ratio matchingThe key condition is \(R_2/R_1=R_4/R_3\).
Common modeMismatch converts shared input voltage into output error.

Detailed theory: exact four-resistor transfer, differential/common-mode decomposition, and CMRR

Perfect subtraction requires ratio matching, not merely four equal resistor values.

1. General transfer function without assuming matched ratios

The noninverting input is set by the divider \(R_3\)-\(R_4\):

\[ v_+=\alpha v_2, \qquad \alpha=\frac{R_4}{R_3+R_4}. \]

For an ideal op-amp in linear negative feedback, \(v_-=v_+=\alpha v_2\). Apply KCL to the inverting node:

\[ \frac{v_1-v_-}{R_1} +\frac{v_o-v_-}{R_2}=0. \]

Solving gives the exact ideal-op-amp transfer for arbitrary resistor values:

\[ \boxed{ v_o= \left(1+\frac{R_2}{R_1}\right) \frac{R_4}{R_3+R_4}v_2 -\frac{R_2}{R_1}v_1 }. \]

This equation is the correct starting point for mismatch analysis.

2. Ratio matching and ideal subtraction

Define

\[ k=\frac{R_2}{R_1}. \]

If the second ratio is matched so that

\[ \boxed{\frac{R_2}{R_1}=\frac{R_4}{R_3}=k}, \]

then

\[ \frac{R_4}{R_3+R_4} =\frac{k}{1+k}, \]

and therefore

\[ \boxed{v_o=k(v_2-v_1)}. \]

The circuit responds only to the difference between its inputs, with differential gain \(A_d=k\).

3. Differential and common-mode decomposition

Represent the two inputs as

\[ v_d=v_2-v_1,\qquad v_{cm}=\frac{v_1+v_2}{2}, \] \[ v_1=v_{cm}-\frac{v_d}{2}, \qquad v_2=v_{cm}+\frac{v_d}{2}. \]

Write the arbitrary-ratio transfer as \(v_o=c_2v_2+c_1v_1\), where

\[ c_1=-\frac{R_2}{R_1}, \qquad c_2= \left(1+\frac{R_2}{R_1}\right) \frac{R_4}{R_3+R_4}. \]

Substitution yields

\[ \boxed{v_o=A_dv_d+A_{cm}v_{cm}}, \] \[ \boxed{ A_d=\frac{c_2-c_1}{2}}, \qquad \boxed{ A_{cm}=c_1+c_2}. \]

For perfect matching, \(c_2=k\), \(c_1=-k\), \(A_d=k\), and \(A_{cm}=0\).

4. CMRR and small resistor-ratio mismatch

The common-mode rejection ratio is

\[ \boxed{ \mathrm{CMRR}=\left|\frac{A_d}{A_{cm}}\right|}, \qquad \boxed{ \mathrm{CMRR}_{dB} =20\log_{10}\left|\frac{A_d}{A_{cm}}\right|}. \]

Suppose \(R_2/R_1=k\) while \(R_4/R_3=k(1+\varepsilon)\), with \(|\varepsilon|\ll1\). First-order expansion gives

\[ A_{cm}\approx\frac{k}{1+k}\varepsilon, \qquad A_d\approx k, \] \[ \boxed{ \mathrm{CMRR}\approx\frac{1+k}{|\varepsilon|}}. \]

For \(k=4\) and a ratio error of \(0.1\%\), this approximation predicts \(\mathrm{CMRR}\approx5000\), or approximately \(74\,\mathrm{dB}\). The relevant error is the mismatch between ratios, which may differ from the tolerance of any single resistor.

5. Common-mode range, clipping, and practical accuracy

Even with perfectly matched external resistors, a real op-amp contributes finite intrinsic common-mode rejection. A useful first-order total error model is

\[ A_{cm,\mathrm{total}} \approx A_{cm,\mathrm{resistors}} +A_{cm,\mathrm{opamp}}. \]

In addition, the internal input nodes must stay within the op-amp input common-mode range, and the required output

\[ v_o=A_dv_d+A_{cm}v_{cm} \]

must remain inside the output-swing limits. Large \(v_{cm}\) can therefore cause failure even when \(v_d\) is small.

Topic 1.5

Summing Amplifier

Extend the inverting-amplifier idea to multiple input branches and use KCL to form a weighted sum.

1Learn→ 2Explore→ 3Guided practice→ 4Check

Summing node and weighted inputs

Each source contributes an independent current to the same virtual-ground node.

Vector circuit
Virtual ground\(v_-\approx0\) while the input terminal draws no current.
Independent weightsEach contribution is weighted by \(R_f/R_k\).
Output\(v_o=-R_f\sum V_k/R_k\).

Detailed theory: general n-input KCL, noise gain, and design variants

Every branch acts independently at the virtual-ground node; the branches combine only through the shared feedback resistor.

1. General closed-loop result from KCL at the summing node

The non-inverting input is grounded, so negative feedback forces \(v_-\approx v_+=0\). Because the ideal op-amp draws no input current, KCL at the summing node requires the three branch currents to sum with the feedback current:

\[ \frac{V_1-v_-}{R_1}+\frac{V_2-v_-}{R_2}+\frac{V_3-v_-}{R_3}+\frac{v_o-v_-}{R_f}=0. \]
Set \(v_-\approx0\): \[ \frac{V_1}{R_1}+\frac{V_2}{R_2}+\frac{V_3}{R_3}+\frac{v_o}{R_f}=0. \]
Solve for \(v_o\): \[ \boxed{v_o=-R_f\left(\frac{V_1}{R_1}+\frac{V_2}{R_2}+\frac{V_3}{R_3}\right)}. \]

Nothing in the derivation required equal input resistors. For \(n\) branches the identical argument gives the general weighted sum

\[ \boxed{v_o=-R_f\sum_{k=1}^{n}\frac{V_k}{R_k}}. \]

Each branch is decoupled from the others: every source sees the same virtual-ground node, so changing \(R_2\) rescales only the \(V_2\) term.

2. Exact gain with finite open-loop gain

Do not impose \(v_-=0\) exactly. With \(v_+=0\), \(v_o=A_{OL}(0-v_-)\), so \(v_-=-v_o/A_{OL}\). Substituting into the node equation and solving for \(v_o\) gives

\[ \boxed{ v_o=\frac{-R_f\left(\dfrac{V_1}{R_1}+\dfrac{V_2}{R_2}+\dfrac{V_3}{R_3}\right)} {1+\dfrac{1}{A_{OL}}\left(1+\dfrac{R_f}{R_1}+\dfrac{R_f}{R_2}+\dfrac{R_f}{R_3}\right)} }. \]

The bracketed correction term is exactly the noise gain defined in the next section. As \(A_{OL}\to\infty\) the denominator approaches 1 and the ideal weighted-sum result is recovered.

3. Noise gain and the equivalent input resistor

Define the equivalent input resistance as the parallel combination of every input branch, i.e. the resistance the summing node sees looking into the sources with all of them set to zero:

\[ \frac{1}{R_{in,eq}}=\frac{1}{R_1}+\frac{1}{R_2}+\frac{1}{R_3}. \]

The noise gain — the gain seen by the op-amp's own input-referred offset voltage and noise, since that error behaves like a signal applied simultaneously to every input — is

\[ \boxed{ 1+\frac{R_f}{R_{in,eq}}=1+\frac{R_f}{R_1}+\frac{R_f}{R_2}+\frac{R_f}{R_3}=1+|g_1|+|g_2|+|g_3| } \]

where \(g_k=-R_f/R_k\) is the signal gain of branch \(k\).

QuantityExpressionMeaning
Branch signal gain\(\displaystyle g_k=-R_f/R_k\)Gain from source \(V_k\) alone to the output.
Equivalent input resistance\(\displaystyle R_{in,eq}=\left(\sum_k 1/R_k\right)^{-1}\)Resistance the summing node sees with all sources grounded.
Noise gain\(\displaystyle 1+R_f/R_{in,eq}\)Gain experienced by input-referred offset and noise; also sets closed-loop bandwidth.

Using the module's example values \(R_1=10\,\text{k}\Omega\), \(R_2=20\,\text{k}\Omega\), \(R_3=10\,\text{k}\Omega\), \(R_f=40\,\text{k}\Omega\): \(R_{in,eq}=4\,\text{k}\Omega\), and the noise gain is \(1+40/4=11\) — the same value obtained from \(1+4+2+4\). As with the single-input inverting amplifier, \(f_{-3\,\mathrm{dB}}\approx f_T/(\text{noise gain})\).

4. Peak current budget and output clipping

Because all branch currents add at the same virtual-ground node regardless of phase or amplitude, the worst case occurs when every branch current peaks in the same direction at once:

\[ |i_{f,\max}|=\frac{|V_{1,pk}|}{R_1}+\frac{|V_{2,pk}|}{R_2}+\frac{|V_{3,pk}|}{R_3}. \]

The output stays within the rails only while \(|v_o|=R_f\,|i_f|\le V_{sat}\), and the op-amp must still supply both the feedback current and any load current, \(i_o=i_f+i_L\), exactly as in the single-input inverting amplifier.

In the module's numeric example, \(i_1=0.0200\,\text{mA}\), \(i_2=0.0175\,\text{mA}\), \(i_3=0.0100\,\text{mA}\) combine to \(i_f=0.0475\,\text{mA}\) and \(v_o=-1.9\,\text{V}\) — comfortably inside a typical \(\pm12\,\text{V}\) rail. Enough branches near their individual maximums can still sum to a clipped output even though no single branch would clip alone.

5. Design variants: averaging circuits and binary-weighted summers

Two useful special cases follow directly from the general weighted-sum result.

Equal-weight averager. Set \(R_1=R_2=\cdots=R_n=R\) and \(R_f=R/n\):

\[ v_o=-\frac{R_f}{R}\sum_k V_k=-\frac{1}{n}\sum_k V_k, \]

an inverted arithmetic mean of the inputs.

Binary-weighted summer. Choose \(R_k=R\cdot2^{k-1}\) (i.e. \(R,\,2R,\,4R,\dots\)):

\[ v_o=-\frac{R_f}{R}\sum_k \frac{V_k}{2^{k-1}}. \]

If each \(V_k\) is switched between \(0\) and a fixed reference voltage to represent one bit, the output becomes proportional to the binary-weighted code — the same summing structure used as the core of a simple digital-to-analog converter.

Walkthrough task: in the guided walkthrough below, change \(R_2\) only and confirm that just the \(V_2\) term of the weighted sum changes — direct evidence that the branches are decoupled at the virtual-ground node.

Core result

\[ v_o=-R_f\left(\frac{V_1}{R_1}+\frac{V_2}{R_2}+\frac{V_3}{R_3}\right) \]

The input branches need not have equal resistors. Each input is weighted by its own factor \(-R_f/R_k\). With all \(R_k=R_f\) the circuit is a plain inverting adder, \(v_o=-(V_1+V_2+V_3)\); with binary-weighted \(R_k\) it becomes a DAC (walkthrough problem 3).

Bandwidth is set by the noise gain \(1+\sum_k R_f/R_k\), not by any single signal weight: \(f_{-3\,\text{dB}}\approx f_T/(1+\sum_k R_f/R_k)\).

Topic 1.6

Op-Amp Integrator

Replace the feedback resistor with a capacitor and move from an algebraic gain to a time-domain relation.

1Learn→ 2Explore→ 3Guided practice→ 4Check

Integrator topology

Replacing the feedback resistor with a capacitor converts KCL into a differential equation.

Vector circuit
Current continuity\(i_R=i_C\) because the ideal input current is zero.
Output slope\(dv_o/dt=-v_i/(RC)\).
AccumulationThe output is proportional to the time integral of the input.

Detailed theory: governing differential equation, frequency response, and the practical integrator

Replacing the feedback resistor with a capacitor turns an algebraic gain relation into a differential equation.

1. Deriving the governing differential equation

The non-inverting input is grounded, so negative feedback forces \(v_-\approx v_+=0\), exactly as in the inverting amplifier. The input resistor current is

\[ i_R=\frac{v_i-v_-}{R}\approx\frac{v_i}{R}. \]

The feedback element is a capacitor connecting the summing node to the output. Take the voltage across it, measured from the summing-node side to the output side, as \(v_C=v_--v_o\). Since the ideal op-amp draws no input current, KCL requires the resistor current to flow entirely into the capacitor:

\[ i_R=i_C=C\frac{dv_C}{dt}. \]
Because \(v_-\approx0\) is essentially constant, \(dv_-/dt\approx0\), so \(dv_C/dt=-dv_o/dt\): \[ \frac{v_i}{R}=-C\frac{dv_o}{dt}. \]
Solve for the output slope: \[ \boxed{\frac{dv_o}{dt}=-\frac{v_i}{RC}}. \]

The circuit no longer has a fixed algebraic gain; instead the output slope at every instant is proportional to the instantaneous input.

2. Time-domain solution and the ramp response

Integrating the governing equation from \(0\) to \(t\) gives the general time-domain solution

\[ \boxed{v_o(t)=v_o(0)-\frac{1}{RC}\int_0^t v_i(\tau)\,d\tau}. \]

For a constant input \(V_i\), the integral evaluates directly and the output becomes a linear ramp:

\[ v_o(t)=v_o(0)-\frac{V_i}{RC}\,t. \]

Using the module's example values \(V_i=0.50\,\text{V}\), \(R=10\,\text{k}\Omega\), \(C=0.10\,\mu\text{F}\): \(RC=1.0\,\text{ms}\), the slope is \(-0.50\,\text{V/ms}\), and with \(v_o(0)=0\) the output reaches \(v_o(2.0\,\text{ms})=-1.0\,\text{V}\) — the same result produced by the guided walkthrough.

3. Frequency-domain transfer function

For sinusoidal or complex-exponential signals, replace the capacitor by its impedance \(Z_C(s)=1/(sC)\). The topology is still the inverting structure with \(Z_f=Z_C\) and \(Z_{in}=R\), so

\[ \boxed{H(s)=\frac{v_o(s)}{v_i(s)}=-\frac{Z_C(s)}{R}=-\frac{1}{sRC}}. \]

This is a single pole located at the origin, \(s=0\) — the transfer function has infinite gain at DC. Evaluating at \(s=j\omega\),

\[ H(j\omega)=-\frac{1}{j\omega RC}=\frac{j}{\omega RC}, \qquad |H(j\omega)|=\frac{1}{\omega RC}, \qquad \angle H(j\omega)=+90^\circ. \]

The magnitude falls at \(-20\,\text{dB/decade}\) and reaches unity gain at \(f_0=1/(2\pi RC)\). With the example \(RC=1.0\,\text{ms}\), \(f_0\approx159\,\text{Hz}\): low-frequency content is integrated with large gain, while high-frequency content is attenuated. This same infinite DC gain is what makes an ideal integrator saturate against any DC offset, addressed next.

4. The practical (leaky) integrator

A real op-amp has a nonzero input offset voltage and bias current. Even with \(v_i=0\), these behave like a small residual current at the summing node that the ideal integrator integrates without bound, so \(v_o\) drifts to a rail over time.

The standard fix places a resistor \(R_f\) in parallel with the feedback capacitor, forming a leaky (lossy) integrator. The feedback impedance becomes

\[ Z_f(s)=R_f\,\|\,\frac{1}{sC}=\frac{R_f}{1+sR_fC}, \qquad \boxed{H(s)=-\frac{R_f/R}{1+sR_fC}}. \]
RegimeBehaviorConsequence
DC (\(s=0\))\(H(0)=-R_f/R\), finiteBounds output drift from offset and bias current.
Above the corner, \(f\gg f_c\)\(sR_fC\gg1\Rightarrow H(s)\to-1/(sRC)\)Recovers ideal-integrator behavior for the signal band.
Corner frequency\(\displaystyle f_c=\frac{1}{2\pi R_fC}\)Choose well below the lowest signal frequency of interest.

Below \(f_c\) the circuit behaves like an ordinary inverting amplifier with finite gain \(-R_f/R\); above it, integration is preserved.

5. Slew-rate limits and periodic reset

Even a leaky integrator can only change its output as fast as the amplifier's slew rate \(SR\) permits. If the demanded slope \(|v_i|/(RC)\) exceeds \(SR\), the output cannot track the ideal ramp and becomes slew-rate limited, rounding or distorting the waveform.

Because any sustained nonzero-average input still accumulates over time, many practical integrator circuits — analog computing blocks, ramp generators, switched-integrator converters — include a reset switch across the capacitor that periodically discharges it and restarts the integration from a known initial condition.

Knowledge Check

Ten questions spanning every topic. Each answer reveals a short explanation.

Advanced problem-solving checklist

Use this sequence before selecting an answer or finalizing a design.

1. Classify the topologyIdentify where the signal enters, which path provides negative feedback, and whether the output is expected to invert.
2. Verify assumptionsCheck that feedback is negative and that the calculated output can remain within the rails.
3. Write node equationsUse \(i_+=i_-=0\) and \(v_+\approx v_-\), then apply KCL without skipping signs.
4. Solve symbolicallyKeep resistor ratios and source variables symbolic until the last step.
5. Check nonideal limitsConsider finite gain, noise gain, bandwidth, slew rate, output current, and common-mode range.
6. Test limiting casesSet inputs equal, set \(R_f=0\), let \(A_{OL}\to\infty\), or reduce an input to zero to verify the result.

1. Under ideal linear operation with negative feedback, which statement is valid?

Negative feedback drives the differential input to about \(v_o/A_{OL}\approx0\) (the virtual short), and the very high input resistance makes \(i_+=i_-\approx0\). It is not a physical short: no current flows between the inputs.

2. An inverting amplifier has \(R_1=10\,\text{k}\Omega\) and \(R_f=50\,\text{k}\Omega\). What is its gain?

\(A_{CL}=-R_f/R_1=-50/10=-5\). “+5” drops the inversion; “−0.2” inverts the resistor ratio.

3. Why is a voltage follower useful even though its voltage gain is 1?

A follower has very high input resistance and very low output resistance, so a weak source can drive a heavy load without its voltage collapsing (walkthrough: Noninverting, problem 3). Output-current limits still apply.

4. What is required for ideal common-mode rejection in the four-resistor difference amplifier?

With \(R_2/R_1=R_4/R_3\) the common-mode gain is zero. Any mismatch lets part of the common-mode input reach the output, giving a finite CMRR (walkthrough: Difference, problem 3).

5. What happens when the required output exceeds the supply rails?

The ideal equations assume the output can supply the demanded voltage. Once \(|A_{CL}v_i|\) exceeds the swing limit the output clips at the rail, feedback loses control, and \(v_-\) no longer equals \(v_+\) (walkthrough: Inverting, problem 3).

6. A noninverting amplifier uses \(R_1=10\,\text{k}\Omega\) (to ground) and \(R_f=90\,\text{k}\Omega\). What is its closed-loop gain?

\(A_{CL}=1+R_f/R_1=1+90/10=10\). The answer 9 is the ratio without the "+1"; −9 uses the inverting formula for a circuit whose signal enters the \(+\) terminal.

7. A summing amplifier has \(R_f=20\,\text{k}\Omega\), \(R_1=10\,\text{k}\Omega\), \(R_2=40\,\text{k}\Omega\), \(V_1=0.5\,\text{V}\), \(V_2=1.0\,\text{V}\). Find \(v_o\).

\(v_o=-R_f\left(\tfrac{V_1}{R_1}+\tfrac{V_2}{R_2}\right)=-(2)(0.5)-(0.5)(1.0)=-1.5\,\text{V}\). The value −2.25 V comes from inverting the resistor ratios; +1.5 V drops the inversion.

8. An integrator with \(R=10\,\text{k}\Omega\), \(C=1\,\mu\text{F}\) and \(v_o(0)=0\) receives a constant \(v_i=+0.2\,\text{V}\) for \(5\,\text{ms}\). What is \(v_o\) at \(t=5\,\text{ms}\)?

\(RC=10\,\text{ms}\), so the slope is \(-v_i/RC=-0.02\,\text{V/ms}\) and \(v_o=-0.02\times5=-0.1\,\text{V}\). A positive input makes the inverting integrator ramp downward.

9. A matched difference amplifier has \(R_1=R_3=10\,\text{k}\Omega\), \(R_2=R_4=50\,\text{k}\Omega\), \(V_1=1.2\,\text{V}\), \(V_2=1.3\,\text{V}\). Find \(v_o\).

\(v_o=(R_2/R_1)(V_2-V_1)=5(0.1)=+0.5\,\text{V}\). The common-mode level (≈1.25 V) is rejected; 12.5 V would result from amplifying the sum instead of the difference.

10. Why is a large resistor \(R_f\) often placed in parallel with the integrator capacitor?

At DC the capacitor is open, so an ideal integrator has unlimited gain and integrates any offset until it saturates. \(R_f\) caps the DC gain at \(-R_f/R\); the circuit still integrates above \(f_c=1/(2\pi R_fC)\). See walkthrough problem “3 · Drift & leaky fix”.
